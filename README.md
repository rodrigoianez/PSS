# 💻 Programación de Servicios Software

Repositorio personal correspondiente a la asignatura **Programación de Servicios Software (PSS)** del **Grado en Ingeniería Informática**.

En este repositorio se recopilan las prácticas y ejercicios desarrollados durante la asignatura.

## 📂 Contenido

* **Práctica 01** — Ejercicios y conceptos iniciales.
* **Práctica 02** — Desarrollo de servicios y aplicaciones.
* **Práctica 03** — Desarrollo y pruebas de una aplicación de Conecta 4.

## 🛠️ Tecnologías

* C#
* .NET
* Visual Studio
* Git
* GitHub

## 🎯 Objetivos

* Desarrollo de aplicaciones mediante servicios software.
* Aplicación de conceptos de programación orientada a objetos.
* Implementación y reutilización de componentes.
* Desarrollo de pruebas unitarias.
* Gestión de proyectos mediante Git.
